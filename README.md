# 職場小白訓練

這是給台灣科技業新鮮人的職場練習題。題目適用各種職位，例如工程、業務、PM、採購與
人資。直接在瀏覽器裡使用，不必註冊。

- **共同基礎**：包含下列主題。
  - 職場用語、電子郵件、會議、團隊內的討論、向上管理與跨部門合作。
  - 勞動法規：工時、加班費、請假、薪資、離職、競業禁止與營業秘密。
  - 績效與職涯。
  - 如何辨識畫大餅、PUA 與慣老闆話術，並保護自己。
  - 真實的職場鬼故事。
- **台廠線**與**外商線**：兩條線互不影響。最終測驗包含兩條線的題目。

每個單元先讀教材，再練習。每次練習從題庫隨機抽 20 題，並打亂選項的順序。沒有做過
與答錯的題目優先出現。總驗收答對至少 90% 就達標。練習進度只儲存在你這台裝置的瀏
覽器裡。如果換裝置或清除瀏覽器儲存的網站內容，進度會從頭開始。

## 內容說明

- 題目與說明由 AI 寫成。法規題附法條原文的出處。新聞、官方說明、文章與論壇的題目
  都附原始網址。出題前，程式下載出處頁面，確認頁面上有對應的文字。
- 沒有官方出處的不成文規則標示為「業界慣例」，各公司的做法可能不同。
- 論壇上的故事標示為「網友自述，未經查證」。非公眾人物的姓名已經移除。
- 勞動法規的數字依製作當時的法令，例如 2026 年的最低工資。內容不是法律意見。遇到
  實際的爭議，聯絡各地的勞工局或律師。

## 檔案

整個網站由 `index.html`、`app.js`、`style.css` 與題庫 `data.js` 組成，沒有後端。
答案與解說都寫在 `data.js` 裡。
